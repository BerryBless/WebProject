# ADR-009 하드닝된 컨테이너와 앱 내장 헬스체크

<!-- doc-harness:section id="summary" hash="7faf13b13ea335b6dc60075cb185fbbb854b38046d77bbe8ad32bc5e78c3b94b" -->
## 결정

api는 chiseled 이미지(셸 없음, 비루트 1654)와 read_only 루트를 쓴다. 모든 서비스에 cap_drop ALL과 no-new-privileges를 적용한다. 헬스체크는 curl 대신 'dotnet PortfolioBlog.Api.dll healthcheck'로 한다.

상태: CONFIRMED
<!-- /doc-harness:section -->

<!-- doc-harness:section id="rationale" hash="566b25ebc888062fbb2480798965cfb7c347188760ecfadb8545dfd0f53b17cf" -->
## 근거

공격 표면을 줄인다. 셸·curl이 없고 HostFiltering이 localhost Host를 거부하므로, 앱 자신이 공개 호스트 이름을 Host 헤더에 실어 /health를 부른다.

코드 근거: `PortfolioBlog.Api/Dockerfile` (22-33), `deploy/docker-compose.yml` (3-13,55,77-83), `PortfolioBlog.Api/Infrastructure/Web/HealthCheckCommand.cs` (11-13)

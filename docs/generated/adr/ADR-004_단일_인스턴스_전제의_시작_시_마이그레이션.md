# ADR-004 단일 인스턴스 전제의 시작 시 마이그레이션

<!-- doc-harness:section id="summary" hash="2c173c70bd5f9c14a47e5d1fec9d5d3ce635932055f320a014aeeb29960dcdd8" -->
## 결정

앱 기동 시 AppDbContext.Database.Migrate()를 직접 호출하고, 이어서 공개 롤 권한을 재계산한다. 설정 검증은 그보다 먼저 한다.

상태: CONFIRMED
<!-- /doc-harness:section -->

<!-- doc-harness:section id="rationale" hash="761ee4de135ffeb3cf6aa1b39abf55899d9cc68bfb691e43772460a3634c234f" -->
## 근거

Program.cs 주석에 단일 인스턴스 배포이므로 시작 시 마이그레이션한다고 적혀 있다(스펙 3.10). 설정 오류가 DB 접속 오류에 가려지지 않게 StartupValidation을 먼저 돌린다.

코드 근거: `PortfolioBlog.Api/Program.cs` (75-88)

# ADR-010 모든 응답에 보안 헤더, 본문 없는 응답에는 본문을 두지 않음

<!-- doc-harness:section id="summary" hash="02cc0a00d2f410ccabf7d9016b626e5832d1aaf1a849dca6755793f331ed09be" -->
## 결정

SecurityHeadersMiddleware가 OnStarting으로 모든 앱 응답에 헤더를 붙인다. HostFiltering 실패 본문은 IncludeFailureMessage=false로 없앤다. Caddy가 직접 만드는 응답(handle_errors 포함)에도 같은 헤더를 붙이고 Server·Via를 지운다.

상태: CONFIRMED
<!-- /doc-harness:section -->

<!-- doc-harness:section id="rationale" hash="787e8a86cd03169dcbb57e40e1867e5ad69cfcd5526deb37195a1009c8273d89" -->
## 근거

코드 주석이 밝힌 불변식은 '본문 있는 응답에는 보안 헤더가 있다'이다. 헤더를 붙일 수 없는 계층(프레임워크 HostFiltering)의 응답은 본문을 없애 이 불변식을 지킨다.

코드 근거: `PortfolioBlog.Api/Program.cs` (38-41,93-98), `deploy/Caddyfile` (23-35,49-61,144-159)

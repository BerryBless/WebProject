1. **[Med] UTC 검증에서 시간대 표기 누락을 놓칩니다 — §6 Fact 1.**  
   .NET 10 파서는 오프셋 없는 문자열도 로컬 시각으로 해석합니다. 따라서 UTC 환경에서는 시간대가 빠진 응답도 `Offset == 0`과 시각 창 검사를 통과할 수 있습니다. `Z` 또는 `+00:00` 존재 검사와 현재 파싱·오프셋 검사를 함께 적용하십시오. 두 표기를 모두 허용하면 특정 표기 방식에 고정되지 않습니다. [공식 .NET 10 구현](https://raw.githubusercontent.com/dotnet/runtime/v10.0.0/src/libraries/System.Text.Json/src/System/Text/Json/JsonHelpers.Date.cs)

2. **[Med] 307 대응이 200 검증을 해결하지 못합니다 — §5.**  
   `AllowAutoRedirect=false`는 리디렉션 추적을 중단하므로 응답이 그대로 307이 됩니다. 진단 목적으로만 사용하고, HTTPS 기준 주소로 요청해 200·본문을 검증하는 대응을 명시하십시오. 기본 `CreateClient()` 결정은 유지할 수 있습니다. [공식 통합 테스트 문서](https://learn.microsoft.com/en-us/aspnet/core/test/integration-tests?view=aspnetcore-10.0)

3. **[Med] 공개 멤버 주석 요구가 충분하지 않습니다 — §4.**  
   신규 테스트 생성자·Fact 메서드에도 `remarks`의 Thread Safety / Memory Allocation / Blocking을 명시하십시오. 특히 동기 Fact 2까지 “각 테스트는 요청 완료를 await”한다고 설명하는 문구는 실제 설계와 다릅니다.

4. **[Low] 변경 범위와 산출물 검증을 일치시켜야 합니다 — §2·§7.**
